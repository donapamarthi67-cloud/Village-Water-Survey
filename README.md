# Village Water Survey

Bilingual English/Telugu Flask + SQLite application for a village water facilities and socio-economic survey.

## Features
- English/Telugu interface
- Multi-section household survey
- Water problem complaint submission
- Complaint number generation and tracking
- Photo uploads
- Water facilities page
- Admin dashboard
- Complaint status management
- CSV exports
- Responsive Bootstrap UI

## Run on Windows
```powershell
cd water_survey
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000
